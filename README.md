> 🏆 **End-to-end Business Intelligence dashboard analyzing $2.3M in retail sales data**

| Feature | Detail |
|:--|:--|
| 📋 Dataset | Sample Superstore — 9,994 orders, 21 columns |
| 📄 Pages | 4-page interactive dashboard |
| 🔢 DAX Measures | 15+ custom KPI calculations |
| 📈 Key Finding | Furniture tables lose money — discount rate of 28–35% causes negative profit |
| 🌍 Top Insight | West Region leads with $725K (32% of total revenue) |

**What I built:**
- ✅ Cleaned & transformed 9,994 rows using **Power Query (M Language)**
- ✅ Designed a **Star Schema** data model with proper table relationships
- ✅ Created **15+ DAX measures** including YoY Growth, Profit Margin %, Time Intelligence
- ✅ Built 4-page dashboard with **slicers, drill-through, KPI cards & conditional formatting**
- ✅ Discovered that discounts >20% result in **–3.8% profit margin**
